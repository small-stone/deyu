# Proposal

## Why

学校德育分数小程序「德育通」已有确认中的 PRD 与完整设计稿（S01–S10b），但 `miniprogram/` 仍是云开发 QuickStart 壳子，无法对照设计评审交互与视觉。需要先交付**无后端、无登录**的全量前端 demo，用写死数据复现 13 个屏幕，作为后续接云开发的可演示基线。

## What Changes

- 用设计稿数据搭建本地 mock，去掉 demo 路径对云开发/登录的依赖（可保留云初始化但不调用）。
- 实现 S01 欢迎/角色入口：作为 demo 角色切换器（家长 / 班主任 / 管理员），非真实鉴权。
- 实现家长端全路径：我的孩子、绑定孩子、分数时间线（S02–S04）及底栏。
- 实现班主任端全路径：创建班级、上传花名册空态、本班首页、花名册、加减分、本班看板（S05a–S08）及底栏。
- 实现管理员端全路径：全校总览、班级均分排行、个人分数排行（S09–S10b）及底栏。
- 「我的 / 设置」设计稿未展开处：轻量占位页（展示当前角色、返回角色入口）。
- 视觉对齐 `designs/index.html` v3（青绿主色、分数环、时间线、奖牌色榜单等）；交互以可点通演示为主，表单可本地更新内存数据，不要求持久化。

## Capabilities

### New Capabilities

- `role-entry`: 欢迎页与三角色入口切换，进入各端门户（demo 模式，无登录）。
- `parent-portal`: 家长查看已绑定孩子、绑定表单、分数详情与加减分时间线。
- `teacher-portal`: 班主任空态引导、本班概览、花名册、加减分、本班排名看板。
- `admin-portal`: 管理员全校总览、班级均分排行与个人分数排行。

### Modified Capabilities

- （无）项目尚无既有 specs。

## Impact

- 主要改动目录：`miniprogram/`（页面、样式、mock、`app.json` 路由与 tabBar 或自定义底栏）。
- 参考源：`designs/index.html`、`designs/mockups/`、`docs/德育分数小程序-需求文档.md`。
- 不改动云函数与真实数据模型实现；本期不引入后端 API。
- 后续接真登录/云库时，可替换 mock 层并保留页面结构。
