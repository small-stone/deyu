# 德育分数小程序 — 产品需求文档（PRD）

> 版本：v1.0  
> 日期：2026-09-30  
> 状态：设计确认中  
> 产品名（暂定）：**德育通**

---

## 1. 产品概述

### 1.1 背景与目标

学校需要统一管理学生德育分数：每位学生初始 60 分，班主任可按事由加分或扣分。家长需能随时查看孩子分数与变动记录；管理员与班主任需要班级/全校排名与数据看板，便于掌握最高分、最低分与整体分布。

### 1.2 产品定位

微信小程序，基于云开发，面向 **管理员 / 班主任 / 家长** 三类角色，完成花名册管理、分数变更、亲子绑定查询与排名看板。

### 1.3 核心价值

| 角色 | 价值 |
|------|------|
| 管理员 | 全校数据总览、跨班对比、异常分数预警 |
| 班主任 | 一键导入学籍、快速加减分并留痕 |
| 家长 | 绑定孩子后透明查看分数与事由时间线 |

## 2. 角色与权限

### 2.1 角色定义

| 角色 | 说明 | 典型操作 |
|------|------|----------|
| **管理员** | 学校层面运营/政教处账号 | 查看全校数据、班级列表、排名看板；管理班主任账号（可选） |
| **班主任** | 负责一个或多个班级 | 上传/维护花名册；对本班学生加减分；查看本班排名与看板 |
| **家长** | 学生监护人 | 输入姓名+身份证号绑定孩子；查看已绑定孩子的分数与加减分记录 |

### 2.2 权限矩阵

| 功能 | 管理员 | 班主任 | 家长 |
|------|:------:|:------:|:----:|
| 查看全校数据 | ✓ | ✗ | ✗ |
| 查看本班数据 | ✓ | ✓ | ✗ |
| 上传/编辑花名册 | ✓（可代管） | ✓（本班） | ✗ |
| 加减分并填写事由 | ✓（可代管） | ✓（本班） | ✗ |
| 绑定孩子 | ✗ | ✗ | ✓ |
| 查看孩子分数与历史 | ✓ | ✓（本班） | ✓（已绑定） |
| 排名 / 看板 | ✓（全校/班级） | ✓（本班） | ✗（或仅展示自家孩子名次，见 5.4） |

### 2.3 登录与身份

- 使用微信授权登录获取 `openid`。
- 首次进入选择/申请角色：
  - **家长**：默认开放，绑定后即可使用。
  - **班主任 / 管理员**：由已有管理员开通，或使用邀请码/手机号白名单激活（实现阶段确认）。
- 同一微信账号原则上只对应一种主角色；若需兼岗，由管理员在后台切换（一期可不支持多角色切换）。

## 3. 核心业务规则

### 3.1 分数规则

| 规则项 | 说明 |
|--------|------|
| 初始分 | 每位学生创建时德育分为 **60 分** |
| 加分 | 班主任填写分值（正数）+ 必填事由 |
| 减分 | 班主任填写分值（正数表示扣多少）+ 必填事由；系统记录为负向变动 |
| 分值精度 | 加减分分值与学生总分均支持 **最多一位小数**（如 1.5）；录入超过一位时按一位小数处理 |
| 分数下限 | **允许负分**；一期不设硬下限，可继续扣分 |
| 分数上限 | 一期建议不设硬上限，或可配置（如 100） |
| 变更不可篡改 | 已提交的加减分记录不可删除；纠错通过「冲正」再记一条反向记录（一期可简化为仅支持新增） |

### 3.2 学生唯一标识

- 学生主键建议：`身份证号`（脱敏展示）。
- 花名册必填字段：姓名、身份证号、班级、学号（可选）、性别（可选）。
- 家长绑定校验：姓名 + 身份证号与花名册完全匹配方可绑定。

### 3.3 绑定规则

- 一个家长账号可绑定 **多个** 孩子。
- 一个孩子可被 **多个** 家长绑定（如父母双方）。
- 解绑：家长可主动解绑；解绑后不再可见该生数据。
- 绑定失败：姓名或证件号不匹配时提示「未找到学生，请核对信息或联系班主任」。

### 3.4 班级与学年

- 学生归属班级；班主任关联班级。
- 一期按「当前学年」单一周期统计；换届/升班规则二期补充。

## 4. 功能需求详述

### 4.1 家长端

#### F-P01 绑定孩子

- 输入：学生姓名、身份证号。
- 校验通过后加入「我的孩子」列表。
- 支持继续绑定其他孩子。

#### F-P02 孩子列表与切换

- 展示已绑定孩子卡片：姓名、班级、当前德育分、近期变动摘要。
- 多孩时可切换查看对象。

#### F-P03 分数详情与时间线

- 展示当前总分（大数字强调）。
- 加减分记录列表：时间、类型（加/减）、分值、事由、操作人（班主任姓名）。
- 支持按时间倒序；可选筛选「仅加分 / 仅减分」。

### 4.2 班主任端

#### F-T00 首次初始化（创建班级 + 花名册）

班主任账号激活后，若尚未关联班级，进入**初始引导**，不可直接使用加减分 / 看板。

**步骤 1 · 创建班级**

- 必填：班级编号（展示名如「352」「353」）
- 选填：学年（默认当前学年）
- 提交后创建 `classes` 记录，并绑定当前班主任

**步骤 2 · 上传花名册**

- 班级已创建但学生数为 0 时，引导上传花名册（Excel/CSV）或提示可稍后手动添加
- 提供模板下载；导入成功后进入本班首页
- 允许「暂时跳过」进入空班级，但加减分入口在无学生时禁用并提示先添加学生

**空状态规则**

| 状态 | 展示 | 可操作 |
|------|------|--------|
| 无班级 | 创建班级引导页 | 仅可创建班级 |
| 有班级、0 学生 | 上传花名册引导页 | 导入 / 手动添加 / 跳过 |
| 有班级且有学生 | 本班首页 | 全部功能 |

#### F-T01 花名册上传

- 支持：
  1. Excel/CSV 批量导入（模板下载）；
  2. 手动逐条新增。
- 导入结果反馈：成功数、失败行及原因（证件号重复、必填缺失等）。
- 可编辑、停用学生（转班/退学标记，一期可做「移出本班」）。
- 初始化流程中的首次导入与日常「花名册」页共用同一套导入能力。

#### F-T02 学生列表

- 本班学生列表，展示姓名、学号、当前分。
- 支持搜索姓名；按分数升降序排序。

#### F-T03 加减分

- 选择学生 → 选择加分/减分 → 输入分值 → **必填事由** → 确认提交。
- 分值支持小数，**最多一位小数**（如 `0.5`、`1.5`）；提交后总分与变更记录均按一位小数精度保存。
- 提交成功后即时更新总分，并写入变更记录。
- 常用事由快捷标签（可选，如「值日优秀」「迟到」「助人为乐」），点击可填入事由框，仍可编辑。

#### F-T04 本班看板与排名

- 见第 5 节。

### 4.3 管理员端

#### F-A01 全校数据总览

- 指标卡：学生总数、班级数、今日加减分次数、全校平均分、最高分、最低分。
- **低分关注**：展示全校近期低分 / 连续扣分学生，置于班级列表上方，便于巡检。
- 班级列表：展示班级编号、班主任、均分，以及 **最高：xx / 最低：xx**（字号加大，颜色区分）。
- 点击班级进入该班详情，权限等同查看该班班主任视图。

#### F-A02 全校排名看板

- 入口：管理员底栏「排名」。
- **统计维度切换**（二选一）：
  1. **班级平均分排行**：按班级均分从高到低；极值卡展示最高/最低均分班级。
  2. **个人分数排行**：全校学生分数榜；可切换「高分榜 / 低分关注」；极值卡展示最高/最低个人分及所属班级。
- **分数分布**：分段柱状图（**<0** / 0–40 / 41–60 / 61–80 / 81+），**柱顶标注该段人数**；负分段用橙色强调。
- 榜单展示名次、名称（班级名或「姓名 · 班级」）、分数/均分与相对进度条。

#### F-A03 班主任管理（一期建议）

- 创建班主任账号并绑定班级；停用账号。

## 5. 排名与看板

### 5.1 目标用户

管理员、班主任（家长端一期不开放全班公开排名，避免攀比与隐私问题；可选展示「本班大致区间」需产品确认）。

### 5.2 看板指标

| 指标 | 说明 |
|------|------|
| 最高分 / 最低分 | 当前范围（全校或本班）极值及对应学生/班级（脱敏策略见 5.3） |
| 平均分 | 算术平均 |
| 分数分布 | 分段人数（**<0** / 0–40 / 41–60 / 61–80 / 81+），图表标注人数；负分段橙色 |
| 今日变动 | 今日加分次数、减分次数、净变动 |
| 排行榜 | 管理员：班级均分榜 / 个人分榜；班主任：本班 Top N / Bottom N |

### 5.3 隐私与展示

- 管理员 / 班主任：可见完整姓名与分数。
- 对外公示场景（若后续开放）：建议仅展示名次与分数，姓名脱敏（如「张*」）。

### 5.4 排序规则

- 主排序：当前德育分降序（高分榜）或升序（低分关注榜）。
- 同分：按最近一次加分时间优先，或按学号（实现时固定一种并文档化）。

## 8. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 班级列表 < 300 人时列表秒开；看板聚合可接受 2s 内 |

## 9. 用户流程（关键路径）

### 9.1 班主任首次使用

1. 微信登录 → 邀请码/管理员开通班主任身份  
2. **创建班级**（填写班级编号，如 352）  
3. **上传花名册**（或跳过后续手动添加）  
4. 从学生列表进入 → 加减分并填写事由  
5. 在看板查看本班最高/最低分与排行

### 9.2 家长查看分数

1. 微信登录 → 选择家长身份  
2. 输入姓名 + 身份证号绑定  
3. 在「我的孩子」查看当前分  
4. 进入详情浏览加减分时间线

### 9.3 管理员巡检

1. 打开全校看板查看均分、极值、今日变动  
2. 下钻到异常班级 / 低分学生  
3. 必要时代为查看班级明细

## 11. 验收标准（摘要）

1. 新建学生初始分为 60。  
2. 班主任无班级时只能进入创建引导；有班级无学生时引导上传花名册。  
3. 无事由无法提交加减分；**扣分后总分可为负数**。  
4. 加减分分值支持最多一位小数；提交后总分与时间线按一位小数一致。  
5. 家长仅用正确姓名+身份证号可绑定；错误信息无法绑定。  
6. 一个家长可成功绑定 ≥2 名学生并切换查看。  
7. 加减分后总分与时间线立即一致。  
8. 班主任看板正确显示本班最高分、最低分及排行（含负分）。  
9. 分数分布含 **&lt;0** 分段；管理员可看到全校汇总，且无法被家长角色访问管理接口。

## 12. 设计说明（摘要）

- **视觉基调（v3）**：青绿成长气质 `#0E8F7A`，叶纹氛围底，柔和阴影与玻璃感点缀；体量介于 v1 感染力与 v2 克制之间。  
- **核心视觉锚点**：家长首页 **分数环**；加减分时间线 **连接线 + 卡片**；榜单 **金银铜奖牌色**；角色入口 **左侧色条区分**。  
- **组件规范**：圆角 16–24、按钮高约 46、标题约 20、分数环直径约 108；图标统一线型 SVG。  
- **峰值体验**：家长看到分数环与加分记录；班主任提交加减分后的明确成功态。  
- **详细页面** 见 `designs/index.html`（推荐预览稿）。
